# 2D Interior Mapping 出图规范

给 shader 用的 **2D 预投影**室内图。只出贴图。不改建筑模型。

构图、采样、日夜、命名必须按本文。房间里摆什么、什么风格、什么颜色，生成器自定。

叠模板出图：[`template-2d.png`](./template-2d.png) / [`template-2d.svg`](./template-2d.svg)。远墙白框、四条青线、灭点十字对不上的图，直接作废。

---

## 做得到 / 做不到

| 要 | 这份规范 |
|----|----------|
| 正对窗子，看起来像一间房 | 做得到 |
| 挂上 shader 不拉飞、不裁错 | 做得到（几何必须按下面写死） |
| 斜看、绕楼时地板完全不拧 | **做不到**。斜看 shader 会再投一次透视。这是 2D 的极限；要五面另开，本仓库还没做 |
| 多扇窗看进同一个真实房间 | **做不到**。每扇窗是独立假盒子 |

禁止把远墙画小来「做出纵深」。远墙小于 50% 正方形，shader 会采样错，斜看更拧。

---

## 现行模型（对不上就废）

`studio_3f_im.glb`。不要按旧的扁窗、四层、A/B/C/D 后缀出图。

| 项 | 值 |
|----|----|
| 层 | L0 / L1 / L2，三层 |
| 立面 | 只有南 N、北 S |
| 开间 | B0=西 W，B1=中 C，B2=东 E |
| 窗子 | **正方形 1.7×1.7 m**。shader 不再裁上下，整张 1:1 图都会露出来 |
| 玻璃名 | `Glass_IM_{N\|S}_L{0-2}_B{0-2}` |
| 缺窗 | 南面一层中间是门，**没有** `Glass_IM_S_L0_B1`，不出 S-L0-C |

shader：`FAR_FRAC = 0.5`，窗子按长边 cover。方窗 = 不裁。

---

## 窗网格约定

程序按网格名挂图，不读 Blender 自定义属性。改窗时只保证下面几条。

- 名字必须是 `Glass_IM_{N\|S}_L{0-2}_B{0-2}`。对不上就不挂。
- 南面一层中间是门：不要做 `Glass_IM_S_L0_B1`。
- 窗洞正方形，约 1.7×1.7 m。程序用包围盒算 `roomSize`，虚拟房间边长跟窗边走。
- 朝外法线从名字来：S=+Z，N=−Z。不要靠网格自身法线。
- 玻璃是薄盒子或薄片。太厚会把房间中心算到墙里面。
- 只出南、北图。名字里的 E/W 程序能解析法线，但没有对应贴图。
- `roomCenter` / `roomSize` / `roomNormal` 在加载时写入，不用在 glb 里带。

---

## 硬几何

贴图空间里的房间是 **立方体**，不是扁公寓。宽 = 高 = 进深。

画幅 **2048×2048 PNG**，8 bit，sRGB。UV：图左下为 (0,0)，上为天花近窗，下为地板近窗。图文件从上往下看时，天花在上、地板在下。

像素（原点在图左上，和 Photoshop / 生成器一致）：

| 结构 | 像素 | 说明 |
|------|------|------|
| 远墙 | `[512,512]–[1536,1536]` | **正方形** 1024×1024，正好画面 50%。不是扁矩形 |
| 灭点 | `(1024,1024)` | 远墙正中，也是画面正中 |
| 天花 | 远墙上边 → 图上边 | 梯形。近窗天花 = 图最顶 |
| 地板 | 远墙下边 → 图下边 | 梯形。近窗地板 = 图最底 |
| 左墙 | 远墙左边 → 图左边 | 梯形 |
| 右墙 | 远墙右边 → 图右边 | 梯形 |
| 四条棱 | 远墙四角 → 图四角 | 必须是直线，接到四角，不得提前收住 |

烘图相机：

- 站在 **窗平面**，看向房间，光轴过 (1024,1024)
- 垂直视场角 **`2·atan(0.5) ≈ 53.13°`**，正方形画幅，`sensor_fit = VERTICAL` 或等边
- 虚拟房间边长 = 窗子边长 = **1.7 m**（与 shader 立方体一致）
- 禁止站在房间中间拍肖像，禁止广角把远墙拍得很大，禁止把远墙拍扁

生成时把 `template-2d` 当图层叠上去：白框 = 远墙外沿，青线 = 墙角，红十字 = 灭点。墙角线必须贴着青线走。

## 禁止画成「室内效果图」

下面这些看起来很像装修图，**shader 全部会拧**：

1. 远墙是扁的宽矩形，高度不到画面一半
2. 远墙大于或小于中心 1024 正方形（「约占 50%」不算数，必须是这个框）
3. 灭点不在正中
4. 墙角线不接到图的四角
5. 椅、凳、桌、落地灯放在房间当中
6. 木地板条纹对着窗子伸向灭点（斜看会像地板在弯）
7. 图上有窗框、玻璃格、外立面、窗帘垂到房间中心
8. 吊灯、灯绳、任何离开墙/地/天花的立柱物体

---

## 家具（只限位置，不管样式）

贴图里的家具没有体积。斜看时，离开墙面的东西会变成贴在地/墙上的图案。

只允许贴在面上：远墙、左右墙、天花、地板。墙角盆栽叶子不伸到画面中心。

椅凳若有：整组退到远墙，椅背贴柜或贴墙，离开远墙不超过远墙高度的 1/5。

主体放在远墙矩形里。近窗地板（图下沿）禁止大块空地 + 顺进深木纹；条纹若用，左右走、平行窗子。方窗不再裁 8%，这块会完整露出来。

---

## 灯（只限位置）

灯具种类自定：吸顶灯、台灯、壁灯、柜灯都行。必须贴在天花、墙、或贴墙的家具上。

- 吸顶灯：画在天花梯形，贴天花板。不要画进远墙矩形，不要贴图最顶 4%（y < 82 px）。若沿进深排多盏，走画面中轴 x = 1024。
- 台灯：放在贴远墙的桌/柜上，跟家具一起靠墙。不要房间当中单独立一盏。
- 壁灯、柜灯：贴墙或贴柜。
- 禁止吊灯、灯绳、房间当中的落地灯。

模板黄圈只给吸顶灯参考，不是必须用吸顶灯。

---

## 白天

每张日图配一张夜图。家具、灯位、踢脚线 **像素对齐**，只换光。

- 固有色 + 柔天光，室内能看清，偏清亮
- 灯关：灯罩可见，灯盘不发光，无灯池
- 禁止假太阳、硬光斑、窗格子影子、窗框投影
- 同层各开间日图亮度接近

---

## 夜景光照（出图标准）

一张夜图同时给近看和远看用。不要出两张。近处能看清房间；拉远后整扇窗要是一块亮的，才能泛光。

**光从哪来**

- 只靠屋里的灯。吸顶灯、台灯、壁灯、柜灯都可以，不强制吸顶灯。
- 灯开、够亮。发光的灯罩/灯盘是图里最亮的东西。灯的颜色不限。
- 灯把附近的家具、墙、地照亮，有灯池。
- 禁止从窗子打进来的月光、路灯、假太阳。窗外没有光。

**房间多亮**

- 屋子是被灯照亮的夜室内，不是把日图简单调色，也不是把房间画黑。
- 家具、墙还看得清。角落可以稍暗，暗部不要死黑。
- 灯比墙亮一截。墙不要和灯一样亮，也不要黑成看不清。
- 从窗子外看，这扇窗应该是一块明显的亮斑，不是黑洞。

**禁止**

- 整张过曝、死白一片
- 整张压黑、只剩三个小灯点
- 灯关着、或灯开了但不亮
- 吊灯、灯绳、房间当中的落地灯
- 台灯悬空或不靠墙的家具
- 窗格子影子、窗框投影

同层各开间夜图亮度接近。

---

## 命名

`{day|night}-{N|S}-L{0-2}-{W|C|E}.png`

一层 `L0/`，二层 `L1/`，三层 `L2/`。`B0→W`，`B1→C`，`B2→E`。南面一层没有 C，不出 `S-L0-C`。日夜成对，PNG。

南、北是两套独立假盒子，不要做成「同一间房的前后窗」。

## 给生成器（整段可复制）

正方形 2048×2048 室内预投影图，不是普通室内照片。把 template-2d 当构图：远墙必须是画面正中的正方形，四角正好在 25% 和 75% 网格上；墙角直线连到画面四角；灭点在正中。房间是立方体。相机在窗洞往里看，垂直 FOV 53.13°。家具只贴墙/地/天花，不要房间正中的桌椅，不要吊灯和房间当中的落地灯，不要窗框和玻璃格。灯可贴天花、贴墙，或放在贴墙的桌柜上当台灯。地板禁止木板条指向画面中心。整张图四边接到墙/地/天花。风格、家具、配色、用哪种灯自定。日图灯关、柔天光、无假太阳无窗影。夜图同布局只换光：屋里的灯开、够亮，颜色不限；屋子被灯照亮但不是日图天光；不过曝、不压黑、无窗外月光。从窗子外看应是一块亮斑。

---

## 验收

叠 `template-2d.png` 半透明：

1. 远墙外沿贴白框，误差不超过 20 px。不是扁矩形。
2. 左右墙与天花、地板的交线贴四条青线，接到四角。
3. 灭点在红十字。
4. 发光体贴在天花、墙或贴墙家具上，不悬空、不吊。
5. 方窗会看到整张图：近窗地板没有大块顺进深木纹空地。
6. 无房间正中独立椅/桌/落地灯，无图画窗框，无吊灯。
7. 日夜像素对齐。日图灯关、无硬太阳、无窗影。夜图灯开（吸顶/台灯/壁灯均可）、颜色不限、够亮、屋子被照亮但不压黑不过曝、无窗外月光；从窗外看是亮斑不是黑洞。
8. 南 L0 无 C。不是五面拆分，不是广角公寓效果图。
